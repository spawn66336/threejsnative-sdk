# Support policy

ThreejsNative SDK consumers must pin an exact SemVer and the published
SHA-256 digest. The Web browser policy covers the current and previous stable
Chromium, Firefox, and WebKit generations. Native platform baselines are
published in `docs/sdk/support-matrix.json`.

Use GitHub Issues in `spawn66336/threejsnative-sdk` for reproducible SDK
defects. Include the SDK version, release-manifest digest, platform,
architecture, OS/toolchain version, and a minimal clean consumer.

Support does not cover modified release artifacts, moving `latest` URLs,
unverified MetaHuman content, or internal Unreal/COS toolchains.
