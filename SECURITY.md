# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories
in `spawn66336/threejsnative-sdk`. Do not include credentials, proprietary
assets, or personal data in a public issue.

Supported SDK versions are listed with status `active` in `releases.json`.
Versions marked `withdrawn` or `security-update-required` must not be selected
for new deployments. Security fixes are shipped as new immutable patch
releases; published artifacts are never replaced in place.
